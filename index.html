전공 · 전문 분야

영진전문대학교 컴퓨터정보계열에서 게임메타버스를 전공하고 있습니다. Unity와 C#으로 게임 콘텐츠를 만드는 것을 중심으로 공부하고, 같은 C#을 쓰는 ASP.NET Core와 EF Core, MySQL로 웹 서비스와 데이터베이스까지 다룹니다. 리눅스, 네트워크, SQL 자격증을 준비하면서 서버를 운영하는 데 필요한 기초도 함께 쌓았습니다.

개요

ASP.NET Core로 만든 커뮤니티 웹 애플리케이션입니다. 회원가입에 이메일 인증을 붙였고, SignalR 라이브러리로 실시간 대화 기능을 구현했으며, 날씨 정보를 화면에 보여 줍니다.

주요 기능

  • 이메일 인증 회원가입가입할 때 입력한 이메일로 인증을 마쳐야 계정이 만들어집니다.
  • 실시간 대화SignalR을 사용해 페이지를 새로 고치지 않아도 메시지가 바로 전달됩니다.
  • 날씨 표시날씨 정보를 받아 페이지에 표시합니다.
